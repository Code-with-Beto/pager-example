# Pager View Example

A minimal Expo SDK 57 example for [`PagerView`](https://docs.expo.dev/versions/v57.0.0/sdk/ui/drop-in-replacements/pagerview/) from `@expo/ui`.

## Run

```bash
bun install
bun run ios
```

Use `bun run android` for Android. Swipe between the three pages or use the button to change pages programmatically.

`@expo/ui`'s Pager View supports iOS and Android, not web.
